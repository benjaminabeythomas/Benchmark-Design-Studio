# Benchmark Design Studio

Three.js-based interactive interior design studio.

## Development status

Initial source work is in progress on `dev/first-prototype`. This is not yet a functional or tested application. No public application deployment is configured.

## Planned first prototype

- First-person walkthrough and orbit navigation
- Editable kitchen and bathroom scenes
- Prompt-driven island creation, movement, dimensions and materials
- Interactive cupboards, drawers, taps, doors and lights
- Three editable alternatives, undo/redo and saved design versions
- Bathroom moodboard workflow

## Constraints

Original implementation inspired by Casa Serra's visual experience; no source or assets copied from that repository. No paid APIs, private company records or credentials belong in this repository.
